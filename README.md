# Ivalice Companion

An offline save reader and editor for FINAL FANTASY TACTICS – The Ivalice
Chronicles (Steam Enhanced).

## Download v0.1.6

|                    | Installer                                                                                                              | Portable                                                                                                                    |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Windows            | [Setup](https://github.com/sam-derby/Ivalice-Companion/releases/download/v0.1.6/Ivalice.Companion_0.1.6_x64-setup.exe) | [ZIP](https://github.com/sam-derby/Ivalice-Companion/releases/download/v0.1.6/Ivalice.Companion_0.1.6_x64-portable.zip)     |
| Linux / Steam Deck | [DEB](https://github.com/sam-derby/Ivalice-Companion/releases/download/v0.1.6/Ivalice.Companion_0.1.6_amd64.deb)       | [AppImage](https://github.com/sam-derby/Ivalice-Companion/releases/download/v0.1.6/Ivalice.Companion_0.1.6_x86_64.AppImage) |

Windows: run the installer, or extract the entire ZIP and open
`ivalice-companion.exe`. Requires Windows 10/11 and WebView2.

Linux: install the DEB on Debian/Ubuntu, or make the AppImage executable and
open it. On Steam Deck, use Desktop Mode. **Linux is an early test build.**

- View and edit your party, jobs, abilities and equipment.
- Edit gil, the date, achievements and story progress.
- Copy, move, swap, import or export save slots.

Changes are saved only when you choose Save, with a backup made first. Try it on
a copy of your save.
