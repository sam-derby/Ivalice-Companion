# Ivalice Companion

An offline Windows save reader and editor for **FINAL FANTASY TACTICS - The
Ivalice Chronicles** (Steam Enhanced).

Download v0.1.4 as a
[Windows installer](https://github.com/sam-derby/Ivalice-Companion/releases/download/v0.1.4/Ivalice.Companion_0.1.4_x64-setup.exe)
or
[portable ZIP](https://github.com/sam-derby/Ivalice-Companion/releases/download/v0.1.4/Ivalice.Companion_0.1.4_x64-portable.zip),
and try edits on a copy of your save.
